# Files Included

This package is the lightweight source handoff for the Date Management preview prototype.

Included:

- `package.json`
- `package-lock.json`
- `index.html`
- `vite.config.ts`
- `tsconfig.json`
- `vitest.config.ts`
- `vercel.json`
- `.env.production`
- `.gitignore`
- `public/`
- `src/`
- `mocks/`
- `typings/`
- README/manifest files for handoff context

Excluded:

- `node_modules`
- `dist`
- `.git`
- generated build output
- dependency caches
- local editor/system files

Static preview build:

- Use `../course-preview-github-web-upload/` for the already-built static version.
- That folder is intentionally separate so generated assets do not pollute the source handoff.
